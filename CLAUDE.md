# Բառեր — приложение для изучения армянского

Telegram Mini App (позже — полноценные приложения) для изучения **восточноармянского с нуля** для русскоязычных, прежде всего переехавших в Ереван. Модель — как Duolingo: путь из юнитов-разговоров, короткие уроки, интервальные повторения.

Живая версия: https://marach1993.github.io/barer/ (GitHub Pages из ветки `main`; бот в Telegram открывает эту ссылку).

## Кто есть кто
- **Владелец продукта — Андрей.** Пишет по-русски, отвечать ему по-русски, просто и без жаргона. Он ставит цели, утверждает или отклоняет предложения и сам тестирует приложение дважды в день.
- **Claude — руководитель проекта.** Ведёт бэклог, собирает команду агентов на спринт, приносит отчёты, разбирает решения владельца.
- Агенты-сотрудники (запускаются на задачу): методист, лингвист-редактор, разработчик, тестировщик (всегда независимо от разработчика), разведчик/продуктовый аналитик, позже дизайнер. Роли и процесс — `docs/team-process.md`.

## Правила работы
- Спринт: план → «да/нет/позже» владельца → работа и перекрёстная проверка → отчёт (`docs/sprint-N-report.md`) → фидбек. Ничего крупного без аппрува владельца.
- Решения владельца записывать в `docs/decisions.md` с датой.
- **Контент**: армянский пишет и проверяет лингвист; ереванская разговорная норма, литературный вариант помечается. Без проверки лингвиста контент не выходит.
- Учебник владельца (Д. Л. Петросян, «Полный курс армянского языка», АСТ, 2023) — ориентир по порядку и объяснению грамматики. Тексты и упражнения из него **не копировать**, примеры писать свои.
- Перед выкладкой — прогон в Playwright в размере телефона (390×760 и 360×640, светлая и тёмная тема), проверка консоли.

## Устройство репозитория
- `app.html` — весь код приложения (HTML+CSS+JS в одном файле, без сборщиков и библиотек). Плейсхолдеры `__WORDS__`, `__VERSION__`, `__CURSIVE__` подставляет сборка.
- `words.txt` — база слов: `армянский[;синоним]|русский[;вариант]|категория`. Текст в скобках в русском — необязательное пояснение.
- `cursive.json` — прописные буквы (вырезаны из учебника), base64 PNG-маски.
- `build.py` — сборка: `python3 build.py` → `index.html` (то, что публикуется) и `tts/list.txt`. Всегда пересобирать и коммитить `index.html` вместе с изменениями `app.html`/`words.txt`.
- `tts/` — озвучка: `samples.txt` (пробные фразы), `gen.py` (Azure Speech, секреты `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`), `list.txt` (генерируется). Файл `tts/ALL_WORDS` (с именем голоса внутри) включает озвучку всей базы.
- `.github/workflows/tts.yml` — при изменении `tts/list.txt` генерирует `audio/*.mp3` и `audio/manifest.json`, коммитит и перезапускает публикацию Pages.
- `audio/` — mp3 и `manifest.json` (`ids`: id слова → файл; `samples`: пробы голосов). Приложение читает манифест при старте.
- `docs/` — стратегия, процесс, решения, бэклог, спецификации и отчёты спринтов.

## Ключевая логика (app.html)
- Состояние в `localStorage["barer.v1"]` и в облаке Telegram (CloudStorage, чанки по 3800 символов). Слияние облака — по каждой стороне карточки побеждает запись с большим числом ответов (`rp`).
- Интервальные повторения — `docs/spec-srs.md`: состояние стороны `{st,stp,iv,ez,due,lp,rp}`, логический день с 04:00, сессии утро/вечер, бюджет сессии, рабочий набор новых, оценка по времени ответа.
- Старый формат прогресса `{p:{id:{a,b,r,e,t}}}` мигрирует через `migrateP` (в том числе из облака и резервной копии).
- id слова = `normHy(первый армянский вариант)`; при переименовании слова прогресс по нему теряется — менять осторожно.
- Экранная клавиатура повторяет раскладки iOS (армянская и русская, слой 123).
