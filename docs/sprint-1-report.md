# Спринт 1 — отчёт (23.11.2026)

## Сделано
1. **Интервальное повторение слов** (спека методиста: упрощённый SM-2 + время ответа).
   - Режим «Сессия»: 100 ответов, сначала слова в обучении, потом повторы по сроку, потом новые (до 20 в день, по 10 за сессию, 4 в работе одновременно).
   - Новое слово: карточка-знакомство → вопрос через 3 карточки → через 8 → закрепление в следующей сессии → повторы через 1, 3, 7… дней. Сторона Рус→Հայ открывается после Հայ→Рус.
   - Быстрый верный ответ двигает интервал сильнее (скорость нормируется по длине ответа и подстраивается под темп).
   - Статусы вместо «12/50»: Новое / Учу / Знакомо / Знаю / Выучено; после ответа «Следующий раз: через N дней».
   - Свободная практика «Все слова» и «Трудные» (слова, которые забывались).
   - Утро и вечер — отдельные сессии; конец сессии с прогнозом на завтра и кнопкой «Ещё 20».
2. **Перенос прогресса**: старые счётчики превращены в интервалы (≥50 верных → 30 дней и т.д.), нагрузка разложена: не больше 40 повторов сегодня и 60 в день дальше. Работает и для облака Telegram, и для резервной копии.
3. **Алфавит**: входная проверка (39 букв по разу; после 10 быстрых верных ответов — «пропустить»), «Я только начинаю» для новичков, сессия букв (знакомство → буква→звук → звук→буква → пропись по флажку), буква «выучена» после интервала ≥7 дней в обе стороны. Старый прогресс по буквам перенесён.
4. **Клавиатура**: новая армянская раскладка iOS (ряды как на скриншотах), русская ЙЦУКЕН, кнопка 123 с армянской пунктуацией, ⌄, долгое нажатие ь→ъ.
5. **Озвучка — конвейер готов**: GitHub Actions + Azure Speech (голоса Анаит и Айк). Ждёт ключ. 20 пробных фраз подобраны лингвистом (ղ, ռ/ր, ը, придыхательные, вопросы, длинная фраза). В приложении: кнопка-динамик, автоозвучка, панель «Проба озвучки» в настройках.
6. **Лингвист** проверил все 519 строк, исправлено:
   - սիսեռ — «нут» (горох — ոլոռ, добавлен); խարտյաշ — «белокурый», не «рыжий»; ջահ + «люстра»; թոռ + «внучка»; երկար + «длинный»; գալ без «ходить»; «ոտքով գնալ» вместо «գնալ ոտքով».

## Что не получилось / ограничения
- Бесплатные варианты озвучки не подошли: в бесплатном сервисе Microsoft армянских голосов нет; модель Meta MMS — только западноармянский. Нужен официальный Azure (бесплатный тариф покрывает базу с запасом).
- Автоматической оценки произношения для армянского сейчас нет ни у одного крупного сервиса (по данным разведки). План — «запиши себя и сравни с эталоном».

## Вопросы к преподавателю (от лингвиста)
1. վարտիք — имелись в виду брюки (тогда տաբատ) или трусы/шаровары?
2. երամ / երամակ — разделить на «стая (птиц)» и «табун»?
3. մազ / հեր / ծամ — развести (ծամ = коса)?
4. ավանակ / էշ — объединить или ավանակ = «ослик» (книжн.)?
5. երազ — оставить только «сон» (мечта = երազանք)?
6. թիվ — «число» или «цифра» (թվանշան)?
7. գիր — в каком значении (буква, письменность, почерк)?
8. իրական — если «настоящий», не իսկական ли?
9. ճչալ (визжать?), կեռ (кривой?), անուշ (приятный?), գերել (пленить?) — в каком значении давались?
10. Учим разговорную или литературную норму (չպոկես / մի՛ պոկիր, Ո՞նց ես / Ինչպե՞ս ես, օր օրի / օրեցօր)?
11. ելնել — «выходить» или «вставать»?

## Разведка — главное
- Курса армянского нет ни в Duolingo, ни в Babbel, ни в официальном Memrise. Для русскоязычных и восточного армянского полноценного продукта не нашли — ниша свободна.
- Azure: синтез hy-AM (Анаит, Айк) и распознавание есть; оценки произношения для hy-AM, скорее всего, нет. Google: распознавание есть, синтеза нет. Yandex: армянского нет.
- Шаблон урока-ситуации (5–7 мин): сценка с аудио → ключевые фразы → узнавание → ввод → «моя реплика» с записью голоса → культурная заметка.
- Топ идей: озвучка, серия дней + дневная цель, уроки-ситуации, «запиши и сравни», чтение слов в алфавите, диктант/аудирование, сборка фразы из плиток, «Test Out» темы.
