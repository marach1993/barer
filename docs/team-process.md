# Команда и процесс

| Роль | Кто | Отвечает за |
|---|---|---|
| Владелец продукта, тестировщик в жизни | Андрей | цели, аппрув/отказ, ежедневное использование (утро + вечер) |
| Руководитель проекта | Claude | бэклог, планирование, сборка команды, отчёты |
| Методист | агент | как учить: структура юнитов и уроков, повторения, нагрузка |
| Лингвист-редактор | агент (+ второй агент на перекрёстную проверку) | армянский и переводы; без него контент не выходит |
| Разработчик | Claude / агент | код |
| Тестировщик | агент, независимый от разработчика | прогон в размере телефона, баги со шагами воспроизведения |
| Разведчик / продуктовый аналитик | агент | тренды, конкуренты, отзывы пользователей, требования к MVP; разбор скриншотов Duolingo от владельца |
| Дизайнер | позже | визуальный язык (после того, как модель станет рабочей и удобной) |

## Спринт
1. **Планирование**: ПМ приносит задачи с пользой и сложностью → владелец: да / нет / позже.
2. **Работа**: агенты делают и проверяют друг друга (лингвист ↔ лингвист, тестировщик ↔ разработчик).
3. **Отчёт**: что сделано, что изменилось для пользователя, что открыто, решения на аппрув. Файл `docs/sprint-N-report.md`.
4. **Фидбек владельца** → задачи следующего спринта.

## Источники решений
- Разбор вживую: владелец присылает скриншоты/записи экрана Duolingo — разведчик раскладывает на механики.
- Исследования рынка и трендов под конкретный вопрос (отзывы пользователей армянских приложений, бенчмарки удержания, требования к MVP перед рекламой).
- Аналитика собственного приложения — когда появятся пользователи (после запуска рекламы).
- Отзывы жены и друзей владельца.
